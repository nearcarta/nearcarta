One full loop on testnet, timed

The house agent (NEAR AI, Confidential model) pays a listed shop, then tries a fake invoice. The charter contract allows the first and refuses the second on chain, and both land in the public ledger. No wallet needed: it uses the shared testnet runner (rate-limited). Goal: under 2 minutes, including a cold API wake-up.

Why no NEAR Intents in this loop: Intents and 1Click run on mainnet only and have no testnet, so the loop uses testnet-native rails (a NEAR function call and a NEP-297 event).
