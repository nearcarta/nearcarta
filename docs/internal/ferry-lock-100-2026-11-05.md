## Stale “Downgrade refused” — root cause (exact)

File: `app/design/D8_shops/shops/ferry.js`

1. Tag starts hidden: `tags[1]` html `'Downgrade refused'`, cls `'no hide'` (line 79).
2. Every `*act` (success **or** refuse) runs the privacy echo beat and **shows** the tag: `tags[1].el?.classList.remove('hide')` (line 133).
3. On refuse: early return with `paintOrder('frozen')` — tag stays visible (intended).
4. On success: `seal.material = sealOk` (line 146) but **HTML tag never hidden** → red “Downgrade refused” remains while order chip → `far bank · delivered`.

Also: entering the room after a prior refuse leaves the previous scene state if the shop instance is reused without remount — same tag. Fix must hide tag on success **and** reset on new quote / Get another quote.
